# Portfólio Pessoal | Henrique Silva Viana

Projeto final da disciplina do curso de **Análise e Desenvolvimento de Sistemas** na UDF.

🔗 **Acesse:** https://henriqueviana7.github.io/portfolio/

## 🔌 Sobre o projeto

Portfólio com o tema **rack de rede e patch panel**, inspirado no meu trabalho como aprendiz de infraestrutura interna:

- O menu lateral é um patch panel: cada página é uma porta RJ45, e o LED verde acende na página atual.
- Cada página usa a cor de um par do cabo no padrão **T568B**: laranja (Início), verde (Sobre), azul (Experiência) e marrom (Contato).
- A página inicial tem uma etiqueta de patrimônio, com código de barras feito só com CSS.

## 🚀 Tecnologias

- HTML5
- CSS3 (Grid, Flexbox, variáveis CSS, `position: sticky` e media queries)
- JavaScript
- Fontes: Barlow Condensed, IBM Plex Sans e IBM Plex Mono (Google Fonts)
- Ícones: Tabler Icons (SVG)

## ✨ Funcionalidades

- Barra lateral fixa no computador, que vira barra no topo no celular
- Menu hambúrguer no celular
- Animações quando a página é rolada (desligadas para quem prefere menos movimento)
- Lightbox para ampliar imagens
- Botão de voltar ao topo
- Design responsivo (computador, tablet e celular)
